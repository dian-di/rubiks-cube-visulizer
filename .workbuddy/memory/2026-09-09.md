# 2026-09-09

## 魔方可视化 App.tsx 组件拆分
- 将单体 `src/App.tsx` 按用户要求拆分为多组件 + 全局 store（zustand）共享消息：
  - `src/lib/cube.ts`：纯逻辑（类型、同心圆几何 `CENTERS/RADII/R/AXIS_NAMES/place`、魔方模型 `initStickers/rotVec/FACE_MOVES/directedCircleAngle` 等），无 React 依赖。
  - `src/store/cubeStore.ts`：zustand 全局 store，持有 `stickers/anim/history/highlight` 状态 + 引擎动作 `pump/commit/doMove/scramble/reset`；逐帧同步引用（`stickersRef/busyRef/queueRef/genRef/animRef`）以模块级变量持有；用 `moveToken/playerClearToken` 计数事件驱动 3D 播放器同步。
  - `src/components/cube/TwistyPlayerView.tsx`：封装 `twisty-player`，订阅 moveToken/playerClearToken 播放/清空。
  - `src/components/cube/MoveControls.tsx`：FACE_KEYS 顺/逆时针按钮 + 打乱/复位 + 历史。
  - `src/components/cube/ConcentricCircle.tsx`：同心圆投影 SVG，持有 `progress` MotionValue 并驱动逐帧动画（原 App 的动画 effect 迁至此）。
  - `src/App.tsx`：仅保留布局 + 键盘监听（doMove）。
- 设计要点：`motionValue` 在 motion@13 未导出，故 `progress` 留在视图层（ConcentricCircle）而非 store；StickerDot 用 `useCubeStore.getState().anim` 在 useTransform 闭包内读当前 deltas，保持逐帧无 re-render。
- 验证受阻：本沙箱 broker 拒绝 `pnpm install` 的文件写入（disk I/O / mkdir deny），无法完成 `pnpm build`；直接 tsc 仅剩环境性模块解析报错（react/motion/zustand/cubing 未链接），无本任务引入的真实错误。需用户在本地 `pnpm install && pnpm build` 验证。
